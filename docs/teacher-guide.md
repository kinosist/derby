# derby 先生向け手順書

クラス全員が同じレースに架空コインを賭け、最後に所持金がいちばん多い人が勝ちになるゲームです。
生徒は Android エミュレータ上のアプリで参加し、先生はブラウザの「管理ページ」で進行します。

- 初めて使うときは「1. 初回の準備」から順に進めてください。
- 2回目以降は「4. 授業当日の流れ」だけで足ります。

---

## 1. 初回の準備(サーバーを公開する)

先生の PC で一度だけ行います。サーバーの公開には Node.js が、アプリのビルド(2. の方法 A)には Flutter と Android Studio が必要です。

1. Cloudflare のアカウントを作ります(無料)。 https://dash.cloudflare.com/sign-up
2. ターミナルでこのプロジェクトの `server` フォルダに移動し、必要なものを入れます。

   ```
   cd server
   npm install
   ```

3. Cloudflare にログインします。ブラウザが開くので「許可」を押します。

   ```
   npx wrangler login
   ```

4. サーバーを公開します。

   ```
   npx wrangler deploy
   ```

   終わると、次のようなアドレスが表示されます。**これを控えてください。**

   ```
   https://derby.<あなたの名前>.workers.dev
   ```

5. 先生用パスワードを決めて登録します。入力を求められるので、決めたパスワードを打ち込みます。

   ```
   npx wrangler secret put TEACHER_KEY
   ```

   パスワードを登録するまでは、誰も管理ページに入れません。

6. ブラウザで `https://derby.<あなたの名前>.workers.dev/admin` を開き、パスワードで入れることを確かめます。

控えたアドレスから、次の2つが決まります。

| 使う場所 | アドレス |
|---|---|
| 先生の管理ページ(ブラウザ) | `https://derby.<あなたの名前>.workers.dev/admin` |
| 生徒のアプリの接続先 | `wss://derby.<あなたの名前>.workers.dev/ws` |

## 2. アプリの準備(生徒のエミュレータに入れる)

アプリには接続先のアドレスを埋め込んでビルドします。方法は2つあり、どちらでも構いません。

### 方法 A: アプリのファイル(APK)を配る(おすすめ)

先生の PC で一度ビルドし、できたファイルを生徒に配ります。生徒側の作業が少なく済みます。

```
flutter build apk --release --target-platform android-x64 --dart-define=SERVER_URL=wss://derby.<あなたの名前>.workers.dev/ws
```

- できあがるファイル: `build/app/outputs/flutter-apk/app-release.apk`(約 18MB)
- 生徒は、起動したエミュレータの画面にこのファイルをドラッグ&ドロップすると、インストールされます。
- 生徒の PC が Apple シリコンの Mac の場合は、`--target-platform android-arm64,android-x64` に変えてビルドしてください。
- `--release` を付けないデバッグ版は約 150MB あり、エミュレータの空き容量が少ないと入りません。

### 方法 B: 生徒が Android Studio でプロジェクトを開いて実行する

1. 生徒の PC にこのプロジェクトのフォルダを配ります。
2. Android Studio で開き、エミュレータを選んで実行します。

接続先を指定しなくても、公開中のサーバー(`wss://derby.versailles747.workers.dev/ws`)につながります。

この方法で生徒の PC でビルドするには、次の2つが必要です。

- **Flutter 3.50 以上**が入っていること。このプロジェクトの Android のビルド設定は Flutter 3.50 に合わせてあります(Android Gradle Plugin 9.3.1、Gradle 9.5.0、Kotlin 2.4.20)。古い Flutter ではビルドできないので、`flutter upgrade` で上げてください。
- **Windows の「開発者モード」がオン**になっていること。オフだと `Building with plugins requires symlink support.` と出て止まります。PowerShell で `start ms-settings:developers` を実行すると設定画面が開きます。変更には管理者権限が必要で、学校の PC では情報システムの担当の方に依頼することになる場合があります。

どちらも難しい場合は、方法 A(APK を配る)を使ってください。APK なら Flutter も開発者モードも要りません。
別のサーバーにつなぎたいときだけ、Run → Edit Configurations… の「Additional run args」に `--dart-define=SERVER_URL=wss://<別のアドレス>/ws` を入れます。

## 3. 授業の前に必ず確認すること

**教室の PC のエミュレータから、実際につながるかを一度試してください。**
学校のネットワークの設定(フィルタリングなど)によっては、Cloudflare に常時接続できないことがあり、これは教室でしか確かめられません。

1. 教室の PC でエミュレータを起動し、アプリを開いて名前を入れ、「参加」を押します。
2. 先生の管理ページの順位表にその名前が出れば OK です。
3. アプリが「再接続中…」のままなら、学校のネットワークが接続を止めている可能性があります。ネットワークの担当の方に「`*.workers.dev` への WebSocket(wss)接続を許可できるか」を相談してください。

あわせて、エミュレータの空き容量が足りているか(アプリが入るか)も確認してください。

## 4. 授業当日の流れ

### 始める前

1. 先生の PC のブラウザ(Chrome か Edge)で管理ページを開き、スクリーンに映します。
2. 前のクラスの生徒が残っていたら、左下の **「全員を退出させる」** を押して部屋を空にします。

### 進め方

管理ページ右下の大きなボタンを押すたびに、次へ進みます。自動では進まないので、説明を挟みながら自分のペースで進められます(レース中だけは、レースが終わると自動的に結果へ進みます。1レースは距離に応じて約23〜33秒です)。

| 画面 | 生徒がすること | 先生が押すボタン |
|---|---|---|
| 参加受付中 | アプリで名前(12文字まで)を入れて「参加」 | 全員そろったら **「試合開始」** |
| 賭け受付中 | 出走表(調子・表情・近走など)を見て、馬券の種類と馬を選び、賭け金を決めて「この馬券を買う」(1レースに10点まで買える) | 右上の「賭け済み ○ / ○ 人」を見て **「締め切ってレース開始」** |
| レース中 | 見るだけ(約23〜33秒)。コースは長く、先頭の馬を追って画面が流れます | なし |
| 結果 | 自分の結果と順位を見る | **「次のレースへ」**(第5レースの後は「最終結果へ」) |
| 最終結果 | 最終順位を見る | もう一度遊ぶなら **「新しい試合」** |

- 1試合は5レースです。1レースあたり、賭ける時間を1〜2分とると、1試合で10〜15分ほどです。
- 「賭け済み ○ / ○ 人」は、いま接続している生徒だけを数えます。全員が賭けるのを待つ必要はなく、いつ締め切っても構いません(賭けなかった生徒は「見送り」になります)。
- 順位表は管理ページの右側に常に出ています。
- 結果の画面では、全員が「どの馬券を買って、いくら増減したか」が公開されます(賭け受付中は、ほかの人の馬券は見えません)。当たった馬券は緑の太字で出ます。
- 配布済みの古いアプリは、できることが少ないまま動き続けます(いちばん古いものは単勝1点だけ、予想屋なし)。全部の機能を使うには、新しいアプリを配り直してください。
- ボタンは、画面が切り替わってから約1秒は押せません。うっかり二重に押しても、レースが飛ばないようにするためです。

### ゲームのルール(生徒への説明用)

- 全員、最初は 1,000 コイン持っています。本物のお金ではありません。
- 1レースは8頭立てです。馬券を買って、着順を予想します。5レースが終わったときに、コインがいちばん多い人が優勝です。

**馬券は4種類あります。**

| 馬券 | 選ぶ馬 | 当たり | 当たりやすさ |
|---|---|---|---|
| 複勝 | 1頭 | その馬が3着以内 | 当たりやすい・倍率は低い |
| 単勝 | 1頭 | その馬が1着 | ふつう |
| 馬連 | 2頭 | 選んだ2頭が1着と2着(順番はどちらでもよい) | 当たりにくい・倍率は高め |
| 3連単 | 3頭 | 1着・2着・3着を順番どおりに当てる | とても当たりにくい・倍率はとても高い(最大 999.9 倍) |

- アプリの賭け画面の上で馬券の種類を選び、馬をタップして、賭け金を決めて「この馬券を買う」を押します。3連単は、1着・2着・3着の順にタップします。
- **1レースに何点でも(10点まで)買えます。** 賭け金は1点ごとに 10 コイン単位で、合計が持っているコインを超える買い方はできません。買わずに見送ってもかまいません。
- 当たった馬券は「賭け金 × 倍率」が戻ってきます。例: 300 コインを 5.1 倍の馬券に賭けて当たると 1,530 コインが戻り、差し引き 1,230 コインの得。外れた馬券の賭け金は戻りません。
- 先生が締め切るまでは、買った馬券を1点ずつ取り消せます(買った馬券の一覧の「×」)。同じ馬券をもう一度買うと、金額を変更できます。
- 倍率は馬の実力(近走の成績など)で決まっています。**その日の「調子」は倍率に入っていません。** 調子の良い馬は倍率のわりに勝ちやすく、調子の悪い馬は倍率のわりに負けやすい傾向があります(ほかの馬の調子にも左右されます)。
- 調子の手がかりは2つあります。出走表の「調子」(絶好調・好調・普通・不調・絶不調)と、馬の「表情」(気合十分・ごきげん・落ち着き・そわそわ・眠そう)です。**どちらも、5回に1回くらいは1段階ずれています。** 2つがそろって良い馬ほど信頼できます。
- 出走表にはほかに、性別と年齢、馬体重、脚質、近3走の着順が出ます(管理ページには人気順も出ます)。脚質はレースの展開(逃げ=前半に飛ばす、追込=後半に伸びる)に表れますが、勝ちやすさには関係しません。馬体重、性別と年齢、距離、馬場状態も、勝ちやすさには関係しません(馬場が重いとレースの時間が少し延びます)。

**予想屋に聞くこともできます。**

| 予想屋 | 料金 | 当たりやすさ |
|---|---|---|
| 競馬新聞 | 30 コイン | ★☆☆ |
| ベテラン予想屋 | 80 コイン | ★★☆ |
| 伝説の予想屋 | 150 コイン | ★★★ |

- アプリの賭け画面で「予想屋に聞く」を開き、料金を払うと、◎(本命)・○(対抗)・▲(単穴)の3頭を教えてくれます。聞いた予想は、出走表の馬にも印で出ます。
- 予想屋は、その日の調子まで見たうえで「倍率のわりに来そうな馬」を選びます。高い予想屋ほど読みが正確ですが、**必ず当たるわけではありません**(いちばん高い予想屋でも、◎が1着になるのは4回に1回くらいです)。
- **料金はその場で引かれ、外れても戻りません。** 聞けるのは賭け受付中だけで、1レースにつき各予想屋1回までです。予想は聞いた本人にしか見えません(聞いた人が口で教えるのは止められません)。
- 料金を払ったあとに 10 コイン以上残らない場合は、聞けません。結果の画面に出る「増減」には、予想屋の料金は含まれません。
- 出走表の「調子」と「表情」をよく読める人にとっては、予想屋の予想はそれと近い内容になります。読むのが苦手な人ほど、予想屋が役に立ちます。
- 結果の画面では、3人の予想と、◎が1着だったかどうかが全員に公開されます。
- コインがほとんどなくなっても(10 コイン未満)、次のレースの前に 100 コインもらえます。

## 5. 困ったとき

| 起きたこと | 対処 |
|---|---|
| 生徒が「その名前は使われています」と出て入れない | 同じ名前の人が接続中です。別の名前(名字を足すなど)で入ってもらいます。 |
| 生徒がアプリを閉じてしまった | もう一度開けば、名前を入れ直さなくても続きから戻ります。 |
| エミュレータを作り直した・アプリを入れ直した | 同じ名前で入り直せば、所持金を引き継いで戻れます。 |
| アプリが「再接続中…」になった | ネットワークが切れています。つながれば自動で戻ります。直らないときはアプリを開き直します。 |
| 「ほかの画面で同じ名前が使われたため、接続を終了しました」と出た | 同じ生徒が別の画面(別のエミュレータなど)で入り直しました。使う画面を1つに決め、そちらで続けます。 |
| ふざけた名前で入った生徒がいる | 管理ページの順位表で、その人の行の「退出」を押します。 |
| 生徒が名前を打ち間違えた | 試合が始まる前(参加受付中)なら、アプリ右上の「︙」→「退出する」で名前の入力に戻れます。古い名前は管理ページで「退出」させてください。試合が始まった後は、管理ページでその生徒を「退出」させると、名前の入力に戻ります。 |
| 試合を最初からやり直したい | 左下の「試合をリセット」。参加者はそのままで、全員 1,000 コインに戻ります。 |
| 別のクラスで使う | 左下の「全員を退出させる」で部屋を空にしてから始めます。 |
| 管理ページのパスワードを変えたい | `npx wrangler secret put TEACHER_KEY` をもう一度実行します。 |
| 管理ページを閉じてしまった | 開き直せば続きから操作できます(同じブラウザならパスワードの再入力も不要です)。 |

### 知っておくとよいこと

- 部屋は1つだけです。同じ時間に2つのクラスで別々に遊ぶことはできません。
- 参加できるのは最大 60 人です。
- Cloudflare は無料プランで動く構成にしてあり、1クラスの授業で使う程度なら無料の範囲に収まる見込みです。正確な上限は Cloudflare の料金ページで確認してください。
- 試合の途中経過はサーバーに保存されるので、先生の PC やブラウザを閉じても試合は消えません。過去の試合の記録は残りません。
