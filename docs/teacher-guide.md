# derby 先生向け手順書

クラス全員が同じレースに架空コインを賭け、最後に所持金がいちばん多い人が勝ちになるゲームです。
生徒は Android エミュレータ上のアプリで参加し、先生はブラウザの「管理ページ」で進行します。

- 初めて使うときは「1. 初回の準備」から順に進めてください。
- 2回目以降は「4. 授業当日の流れ」だけで足ります。

---

## 1. 初回の準備(サーバーを公開する)

先生の PC で一度だけ行います。Node.js が入っている必要があります。

1. Cloudflare のアカウントを作ります(無料)。 https://dash.cloudflare.com/sign-up
2. ターミナルでこのプロジェクトの `server` フォルダに移動し、必要なものを入れます。

   ```
   cd server
   npm install
   ```

3. Cloudflare にログインします。ブラウザが開くので「許可」を押します。

   ```
   npx wrangler login
   ```

4. サーバーを公開します。

   ```
   npx wrangler deploy
   ```

   終わると、次のようなアドレスが表示されます。**これを控えてください。**

   ```
   https://derby.<あなたの名前>.workers.dev
   ```

5. 先生用パスワードを決めて登録します。入力を求められるので、決めたパスワードを打ち込みます。

   ```
   npx wrangler secret put TEACHER_KEY
   ```

   パスワードを登録するまでは、誰も管理ページに入れません。

6. ブラウザで `https://derby.<あなたの名前>.workers.dev/admin` を開き、パスワードで入れることを確かめます。

控えたアドレスから、次の2つが決まります。

| 使う場所 | アドレス |
|---|---|
| 先生の管理ページ(ブラウザ) | `https://derby.<あなたの名前>.workers.dev/admin` |
| 生徒のアプリの接続先 | `wss://derby.<あなたの名前>.workers.dev/ws` |

## 2. アプリの準備(生徒のエミュレータに入れる)

アプリには接続先のアドレスを埋め込んでビルドします。方法は2つあり、どちらでも構いません。

### 方法 A: アプリのファイル(APK)を配る(おすすめ)

先生の PC で一度ビルドし、できたファイルを生徒に配ります。生徒側の作業が少なく済みます。

```
flutter build apk --release --target-platform android-x64 --dart-define=SERVER_URL=wss://derby.<あなたの名前>.workers.dev/ws
```

- できあがるファイル: `build/app/outputs/flutter-apk/app-release.apk`(約 18MB)
- 生徒は、起動したエミュレータの画面にこのファイルをドラッグ&ドロップすると、インストールされます。
- 生徒の PC が Apple シリコンの Mac の場合は、`--target-platform android-arm64,android-x64` に変えてビルドしてください。
- `--release` を付けないデバッグ版は約 150MB あり、エミュレータの空き容量が少ないと入りません。

### 方法 B: 生徒が Android Studio でプロジェクトを開いて実行する

1. 生徒の PC にこのプロジェクトのフォルダを配ります。
2. Android Studio で開き、メニューの Run → Edit Configurations… を開きます。
3. 「Additional run args」に次を入れます。

   ```
   --dart-define=SERVER_URL=wss://derby.<あなたの名前>.workers.dev/ws
   ```

4. エミュレータを選んで実行します。

この指定を忘れると、アプリは開発用のアドレスにつなごうとして「再接続中…」のままになります。

## 3. 授業の前に必ず確認すること

**教室の PC のエミュレータから、実際につながるかを一度試してください。**
学校のネットワークの設定(フィルタリングなど)によっては、Cloudflare に常時接続できないことがあり、これは教室でしか確かめられません。

1. 教室の PC でエミュレータを起動し、アプリを開いて名前を入れ、「参加」を押します。
2. 先生の管理ページの順位表にその名前が出れば OK です。
3. アプリが「再接続中…」のままなら、学校のネットワークが接続を止めている可能性があります。ネットワークの担当の方に「`*.workers.dev` への WebSocket(wss)接続を許可できるか」を相談してください。

あわせて、エミュレータの空き容量が足りているか(アプリが入るか)も確認してください。

## 4. 授業当日の流れ

### 始める前

1. 先生の PC のブラウザ(Chrome か Edge)で管理ページを開き、スクリーンに映します。
2. 前のクラスの生徒が残っていたら、左下の **「全員を退出させる」** を押して部屋を空にします。

### 進め方

管理ページ右下の大きなボタンを押すたびに、次へ進みます。自動では進まないので、説明を挟みながら自分のペースで進められます(レース中だけは約20秒で自動的に結果へ進みます)。

| 画面 | 生徒がすること | 先生が押すボタン |
|---|---|---|
| 参加受付中 | アプリで名前(12文字まで)を入れて「参加」 | 全員そろったら **「試合開始」** |
| 賭け受付中 | 馬を選び、賭け金を決めて「この内容で賭ける」 | 右上の「賭け済み ○ / ○ 人」を見て **「締め切ってレース開始」** |
| レース中 | 見るだけ(約20秒) | なし |
| 結果 | 自分の結果と順位を見る | **「次のレースへ」**(第5レースの後は「最終結果へ」) |
| 最終結果 | 最終順位を見る | もう一度遊ぶなら **「新しい試合」** |

- 1試合は5レースです。1レースあたり、賭ける時間を1〜2分とると、1試合で10〜15分ほどです。
- 「賭け済み ○ / ○ 人」は、いま接続している生徒だけを数えます。全員が賭けるのを待つ必要はなく、いつ締め切っても構いません(賭けなかった生徒は「見送り」になります)。
- 順位表は管理ページの右側に常に出ています。

### ゲームのルール(生徒への説明用)

- 全員、最初は 1,000 コイン持っています。本物のお金ではありません。
- 1レースは8頭立てです。**1着になる馬を1頭だけ**予想して賭けます。
- 賭け金は 10 コイン単位で、10 コインから持っている全額まで。賭けずに見送ってもかまいません。
- 馬ごとに倍率(オッズ)があります。**倍率が低い馬ほど勝ちやすく、高い馬ほど勝ちにくい**かわりに、当たると大きく増えます。
- 当たると「賭け金 × 倍率」が戻ってきます。例: 300 コインを 5.1 倍の馬に賭けて当たると 1,530 コインが戻り、差し引き 1,230 コインの得。外れると賭けた 300 コインを失います。
- 先生が締め切るまでは、賭けの変更や取り消しができます。
- コインがほとんどなくなっても(10 コイン未満)、次のレースの前に 100 コインもらえます。
- 5レースが終わったときに、コインがいちばん多い人が優勝です。

## 5. 困ったとき

| 起きたこと | 対処 |
|---|---|
| 生徒が「その名前は使われています」と出て入れない | 同じ名前の人が接続中です。別の名前(名字を足すなど)で入ってもらいます。 |
| 生徒がアプリを閉じてしまった | もう一度開けば、名前を入れ直さなくても続きから戻ります。 |
| エミュレータを作り直した・アプリを入れ直した | 同じ名前で入り直せば、所持金を引き継いで戻れます。 |
| アプリが「再接続中…」になった | ネットワークが切れています。つながれば自動で戻ります。直らないときはアプリを開き直します。 |
| ふざけた名前で入った生徒がいる | 管理ページの順位表で、その人の行の「退出」を押します。 |
| 生徒が名前を打ち間違えた | アプリ右上の「︙」→「退出する」で名前の入力に戻れます。古い名前は管理ページで「退出」させてください。 |
| 試合を最初からやり直したい | 左下の「試合をリセット」。参加者はそのままで、全員 1,000 コインに戻ります。 |
| 別のクラスで使う | 左下の「全員を退出させる」で部屋を空にしてから始めます。 |
| 管理ページのパスワードを変えたい | `npx wrangler secret put TEACHER_KEY` をもう一度実行します。 |
| 管理ページを閉じてしまった | 開き直せば続きから操作できます(同じブラウザならパスワードの再入力も不要です)。 |

### 知っておくとよいこと

- 部屋は1つだけです。同じ時間に2つのクラスで別々に遊ぶことはできません。
- 参加できるのは最大 60 人です。
- Cloudflare は無料プランで動く構成にしてあり、1クラスの授業で使う程度なら無料の範囲に収まる見込みです。正確な上限は Cloudflare の料金ページで確認してください。
- 試合の途中経過はサーバーに保存されるので、先生の PC やブラウザを閉じても試合は消えません。過去の試合の記録は残りません。
